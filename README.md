# 🧭 IT COMPASS

**IT COMPASS** — веб-приложение для расчёта рейтингов субъектов РФ для IT-специалистов с учётом уровня квалификации на основе объективных метрик.

🛠️ **Статус:** в активной разработке.

## 🗺️ План разработки

- **Интерактивная карта:** Карта России с цветовым градиентом (от красного к зеленому) и инфобоксами при клике на субъект.
- **Выбор профиля:** Смена уровня (`Абитуриент`, `Стажёр` `Junior`, `Middle`, `Senior`) с динамическим пересчётом весов метрик под конкретные приоритеты.
- **Топ-10 субъектов:** Список лучших субъектов РФ для выбранного профиля (позиция, название, балл).
- **Сравнение субъектов:** Детальное сравнения двух субъектов с определением победителя по метрикам.
- **Поиск субъекта:** Поле ввода и подсветка на карте.
