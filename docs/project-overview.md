# IT Compass

## Summary

A web app for calculating ratings of Russian regions for IT specialists, taking into account their qualification level based on objective metrics. Helps IT professionals choose a region to live and work in.

## Discovery Mode

- **Mode:** greenfield
- **Project state:** partial implementation
- **Interview date:** 2026-10-13
- **Owner:** Stepan Nogtev

## Problem Framing

- **Primary user:** Russian IT specialists choosing a region to work and live in
- **Core problem:** most IT job openings (about 65%) require on-site work, so choosing a region directly affects career prospects
- **Value proposition:** a transparent ranking of regions based on measurable metrics, personalized by qualification level
