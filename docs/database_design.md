# IT Compass

## Общая информация

- **Тип разработки:** Greenfield
- **Состояние проекта:** Частичная реализация
- **Автор документа:** Степан Ногтев

## Краткое описание

Веб-приложение для расчёта рейтинга российских регионов для ИТ-специалистов с учётом их квалификации на основе объективных метрик. Помогает ИТ-специалистам выбрать регион для жизни и работы.

## Анализ предметной области

### Проблематика

- **Основной пользователь:** Российские ИТ-специалисты, выбирающие регион для работы и жизни.
- **Ключевая проблема:** Большинство ИТ-вакансий в России (около 65%) приходится на офисный формат работы[^1], что делает выбор региона проживания фактором, напрямую влияющим на карьерные перспективы.

### Цели проекта

- **Ценностное предложение:** Прозрачный рейтинг регионов на основе измеримых метрик, персонализированный по уровню квалификации.
- **Бизнес-цель:** Отсутствует — учебный проект.

### Целевая аудитория

Целевая аудитория проекта сегментирована по грейду:

| Сегмент | Цель релокации | Болевые точки |
| :------ | :------------- | :------------ |
| **Абитуриент** | Поступить в ведущее образовательное учреждение и попасть в IT-среду | Высокая конкуренция среди поступающих, дорогое жильё, оторванность от семьи |
| **Стажёр** | Пройти стажировку и получить первый коммерческий опыт | Стажировка ограничена по длительности, отсутствие гарантии трудоустройства, низкий уровень оплаты труда |
| **Junior** | Закрепиться в профессии и выйти на стабильный доход | Небольшой опыт и отсутствие финансовой подушки — сложно пережить резкую потерю работы |
| **Middle** | Повысить доход и улучшить условия жизни | Есть что терять: текущая работа и быт, в то время как рост дохода на новом месте не гарантирован |
| **Senior** | Обеспечить семью и выйти на высокий уровень жизни | Переезд затрагивает партнёра и детей: партнёру искать работу заново, детям — менять детский сад или школу |

### Ограниченные контексты

| Подсистема | За что отвечает | Ключевые понятия |
| :--------- | :-------------- | :--------------- |
| **Источники данных** | Сбор и проверка метрик | [*Регион*](#регион-region), Источник, [*Метрика*](#метрика-metric) |
| **Рейтинг регионов** | Нормализация данных, расчёт баллов и отображение на сайте | *Регион*, *Метрика*, [*Грейд*](#грейд-grade), [*Формула*](#формула-formula), [*Валидированная метрика*](#очищенная-запись-метрики-cleanmetricrecord), [*Итоговый рейтинг*](#итоговый-рейтинг-regionrating) |

### Ключевые рабочие процессы

| Процесс | Что запускает | Основные шаги |
| :------ | :------------ | :------------ |
| **1. Импорт сырых данных** | Консольная программа (Этап 1) | 1. Полностью очистить старые записи в БД, если таковые имеются → 2. Скачать CSV-версию Google Таблицы с [*сырыми данными*](#сырая-запись-метрики-rawmetricrecord) по ссылке → 3. Считать строки из файла и сохранить в БД |
| **2. Валидация и нормализация** | Консольная программа (Этап 2, автоматически после Этапа 1) | 1. Считать все сырые данные из БД → 2. Проверить названия *регионов* и *метрик* по справочникам и отсечь строки со значением «Нет данных» → 3. Конвертировать *метрики* в числа и нормализовать их в баллы от 1 до 100 → 4. Записать результат в БД |
| **3. Расчёт итогового рейтинга** | Консольная программа (Этап 3, автоматически после Этапа 2) | 1. Считать нормализованные баллы из БД → 2. Рассчитать общий балл по каждому *региону* при помощи *Формул* → 3. Сохранить финальный результат в БД |
| **4. Просмотр рейтинга с фильтрацией** | Открытие сайта | 1. Выбрать *Грейд* (обязательно) → 2. Настроить фильтр (опционально): выбрать один [*Федеральный округ*](#федеральный-округ-district) ИЛИ выбрать один конкретный *регион* (если ничего не выбрано — выводятся все регионы России) → 3. Получить из БД отфильтрованные данные *Итогового рейтинга* → 4. Отобразить данные на сайте |

## Проектирование базы данных (Концептуальный и логический этапы)

### Сущности

#### Справочные сущности

##### Федеральный округ (District)

| Поле | Тип данных | Ограничения | Описание |
| :--- | :--------- | :---------- | :--- |
| `id` | Integer | PK | Первичный ключ (автоинкремент) |
| `name` | String | NOT NULL, UNIQUE | Название федерального округа |
| `slug` | String | NOT NULL, UNIQUE | Человекопонятный URL |

##### Регион (Region)

| Поле | Тип данных | Ограничения | Описание |
| :--- | :--------- | :---------- | :--- |
| `id` | Integer | PK | Первичный ключ (автоинкремент) |
| `district_id` | Integer | FK, NOT NULL | ID федерального округа из сущности `District` |
| `name` | String | NOT NULL, UNIQUE | Название региона |
| `slug` | String | NOT NULL, UNIQUE | Человекопонятный URL |

##### Метрика (Metric)

| Поле | Тип данных | Ограничения | Описание |
| :--- | :--------- | :---------- | :--- |
| `id` | Integer | PK | Первичный ключ (автоинкремент) |
| `name` | String | NOT NULL, UNIQUE | Название метрики |
| `is_graded` | Boolean | NOT NULL | Разделяется ли метрика по грейдам |

##### Грейд (Grade)

| Поле | Тип данных | Ограничения | Описание |
| :--- | :--------- | :---------- | :--- |
| `id` | Integer | PK | Первичный ключ (автоинкремент) |
| `name` | String | NOT NULL, UNIQUE | Название грейда |
| `slug` | String | NOT NULL, UNIQUE | Человекопонятный URL |

#### Операционные сущности

##### Сырая запись метрики (RawMetricRecord)

| Поле | Тип данных | Ограничения | Описание |
| :--- | :--------- | :---------- | :--- |
| `id` | Integer | PK | Первичный ключ (автоинкремент) |
| `raw_region_name` | String | NOT NULL | Название региона из CSV |
| `raw_metric_name` | String | NOT NULL | Название метрики из CSV |
| `raw_grade_name` | String | NULL | Название грейда из CSV |
| `raw_value` | String | NULL | Значение метрики из CSV |

##### Очищенная запись метрики (CleanMetricRecord)

| Поле | Тип данных | Ограничения | Описание |
| :--- | :--------- | :---------- | :--- |
| `id` | Integer | PK | Первичный ключ (автоинкремент) |
| `region_id` | Integer | FK, NOT NULL | ID региона из сущности `Region` |
| `metric_id` | Integer | FK, NOT NULL | ID метрики из сущности `Metric` |
| `grade_id` | Integer | FK, NULL | ID грейда из сущности `Grade` (пусто для общих метрик) |
| `value` | Decimal | NOT NULL | Валидированное числовое значение |
| `normalized_score` | Decimal | NOT NULL, CHECK (>= 1.0 AND <= 100.0) | Нормализованный балл региона по этой метрике (от 1 до 100) |

##### Итоговый рейтинг (RegionRating)

| Поле | Тип данных | Ограничения | Описание |
| :--- | :--------- | :---------- | :--- |
| `id` | Integer | PK | Первичный ключ (автоинкремент) |
| `region_id` | Integer | FK, NOT NULL | Связь со справочником `Region` (какой регион оценивается) |
| `grade_id` | Integer | FK, NOT NULL | Финальный присвоенный грейд из справочника `Grade` по результатам расчета |
| `total_score` | Decimal | NOT NULL, CHECK (>= 1.0 AND <= 100.0) | Общий балл региона для конкретного грейда |

#### Конфигурационные сущности

##### Формула (Formula)

| Поле | Тип данных | Ограничения | Описание |
| :--- | :--------- | :---------- | :--- |
| `id` | Integer | PK | Первичный ключ (автоинкремент) |
| `grade_id` | Integer | FK, NOT NULL | ID грейда из сущности `Grade` |
| `metric_id` | Integer | FK, NOT NULL | ID метрики из сущности `Metric` |
| `weight` | Decimal | NOT NULL, CHECK (>= 0.0 AND <= 1.0) | Вес метрики |
