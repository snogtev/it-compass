# IT Compass — Глоссарий

## В

* **Вес** — числовой параметр от 0.0 до 1.0, определяющий уровень значимости конкретной метрики для определённого грейда при расчёте итогового рейтинга региона. Сумма всех весов в рамках одного грейда строго равна 1.

## Г

* **Грейд** — уровень квалификации ИТ-специалиста, который влияет на его возможности и требования к релокации.

## И

* **Источник данных** — авторитетный веб-ресурс, содержащий исходные числовые показатели регионов, используемые для расчета рейтинга.
* **Итоговый рейтинг** — результат скоринга одного конкретного региона, выраженный в баллах от 1 до 100.

## М

* **Метрика** — объективный числовой показатель, на основе которого рассчитывается рейтинг регионов.

## О

* **Нормализованная запись метрики** — числовое значение метрики, приведённое с помощью формулы линейной нормализации к единой шкале от 1 до 100.
* **Обратная метрика** — метрика, при которой **минимальное** числовое значение сырой записи метрики даёт максимальный балл в нормализованной записи.

## П

* **Прямая метрика** — метрика, при которой **максимальное** числовое значение сырой записи метрики даёт максимальный балл в нормализованной записи.

## Р

* **Регион** — субъект РФ.
* **Рейтинг регионов** — ключевая часть итоговой информационной системы, которая заключается в расчёте баллов каждого региона по шкале от 1 до 100.

## С

* **Скоринг** — математическая модель создания рейтинга регионов.
* **Сырая запись метрики** — исходное числовое значение метрики в его оригинальных единицах измерения, полученное из источника данных, сохранённое в CSV-файл.
